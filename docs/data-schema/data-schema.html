Proprietary Metrics

Field Unit and Range Current Meaning
riskScore 1 to 10, currently rounded to an integer by computeRiskScore. Higher means higher risk. Inputs include volatility, market cap, volume-to-market-cap ratio, and ATH drawdown.
riskLevel low, medium, or high. Derived from riskScore: low <= 3, medium <= 6, high > 6.
growthPotentialIndex 0 to 100. Composite score from distance from ATH, category-relative market cap, and recent 30-day momentum.
narrativeStrength 0 to 100. Category mapping score, defaulting to 30 when no mapped category is found.
valueVsAth 0 to 100 score. 100 means at ATH, 0 means nearly worthless versus ATH. This is not the raw negative ATH drawdown.
volatilityIndex 0 to 100 score. Computed from 30-day coefficient of variation and scaled with Math.min(100, volatility * 5).

Validation Implementation

  • src/lib/schemas.ts defines Zod schemas for token metrics, generated articles, article quality snapshots, token detail data, price histories, TGE records, search-intent datasets, and search-intent history.
  • scripts/validate-content.ts validates JSON syntax, persisted data-schema contracts, generated article path/type/slug integrity, outbound URLs, TGE preview references, and TGE dataset invariants.
  • scripts/quality-check.ts enforces article quality gates such as word count, FAQ, disclaimer, data density, prohibited phrases, and readability.
  • src/lib/content-loader.ts validates metrics, price histories, and search-intent datasets before returning them. Invalid payloads return null instead of silently defaulting fields.
  • scripts/consolidate-data.ts and scripts/compute-search-intent.ts skip tokens with untrusted market data using the market-data quality checks.

Implemented Contract Decisions

  • Invalid metric, price-history, and search-intent runtime payloads are treated as unavailable data and return null from loader APIs.
  • Build-time content validation fails on schema violations for the documented persisted data files.
  • valueVsAth is clamped to 0-100, and metric summaries interpret high scores as near ATH and low scores as deeply discounted versus ATH.
  • Sitemap and OG files remain build products, not data contracts, so they are intentionally excluded from this schema surface.
  • docs/data-schema/data-schema.json remains the machine-readable contract because the root Markdown source has been removed.
